## Declaração sobre a elicitação (leitura obrigatória)

A equipe **não tem, até esta data, acesso direto** a usuários reais do sistema (observadores, validadores,
equipes de resposta), e os integrantes não moram no litoral. Por isso:

1. A elicitação **realizada** até agora é **documental**: análise de artigos, relatórios e notícias, com
   as fontes citadas. Não houve entrevistas nem observação de campo.
2. Questionário e entrevista estão **planejados**, com status registrado. Só serão descritos como
   realizados quando acontecerem, com data e fonte.
3. Se não houver respostas, a equipe trabalhará com **cenário declarado**, separando fatos de hipóteses.
4. Nada neste documento apresenta como real uma conversa ou resposta que não ocorreu.
